MERIDIAN RUN — Dawn Courier over the Kestrel Isles: you fly the Kestrel Courier K-7, the only mail plane still running the dawn route between the isles. Three sorties with different goals — thread eight signal rings over the islands, drop three supply crates on the glowing beacons, or climb, circle and land back on Meridian Field. Throttle, turn discipline, fuel and damage all matter: stall below flying speed, hit terrain hard, or run the tanks dry and the sortie is over. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC (1st $100).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. W/S throttle, arrow keys pitch and bank, mouse steers, wheel trims throttle, SPACE drops cargo, R restarts the sortie, P pauses, M mutes. `?shot=cover|rings|drop|landing` freezes a staged scene; `?autopilot=rings|cargo|landing` flies the mission on its own.
